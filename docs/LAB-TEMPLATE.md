# Lab NN — Title

**Objective:** One sentence stating the outcome the lab produces.
**Environment:** Hosts involved and their roles.
**Prerequisites:** Labs that must be complete before this one.
**Automation:** The script or stage this lab exercises, if any.
**Duration:** Approximate time to complete.

---

## 1. Scenario

Two to four sentences framing the task as operational work rather than an exercise: the
requirement, and the constraint that shapes the solution.

---

## 2. Design decisions

| Decision | Options considered | Selected | Rationale |
|---|---|---|---|
| | | | |

Only choices a reviewer could reasonably question belong here.

---

## 3. Implementation

Numbered steps. Each states the action, the command, and the expected result. Screenshots
follow the step they evidence, each with a one-line caption:

```markdown
![Concise description](images/NN-nn-short-name.png)
```

Image filenames follow `NN-nn-short-name.png`, where `NN` is the lab number.

## 5. Faults encountered

**Symptom.** Observable behaviour, including exact error text.
**Diagnosis.** How the cause was isolated.
**Cause.** The underlying condition.
**Resolution.** The change made — and whether its effect was re-verified on the server or only in
code. Where it was not re-verified, that is stated.

## 6. Capabilities demonstrated

A short list in job-description vocabulary, without overstatement.

## 7. References
